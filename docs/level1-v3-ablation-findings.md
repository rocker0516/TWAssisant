## 4. 負結果與風險

**(a) 成本主導：排序有效，但不足以跨過 0.585% 成本。**
Top-20 相對 U_t 的超額在所有步、所有 horizon 都為正（+0.266 ~ +0.555pp），IC +0.08~+0.11，所以模型確實在挑「比平均好」的股票。問題是水位：dev 期 U_t 等權淨報酬本身就是負的（旗標日 -0.70 ~ -0.89%，2022 為空頭年，且每筆都扣 0.585%），超額 +0.3~+0.5pp 墊不到零。
- **1D 是機械性的負值**：成本 0.585% 大於典型單日漲跌幅；Top-20 **中位數**淨報酬在六個步驟全部恰為 -0.585%，代表典型入選股的毛報酬是 0——q25 排名在 1D 選到的是「幾乎不動」的低波動股（下緣最高＝波動最小），扣成本後必負；Top-20 日勝率只有 0.098~0.111。1D 在現行成本與目標定義下不具可交易性，任何特徵族都不會改變這一點。
- **5D/10D 才是 ablation 的真正問題**：A 與 B 把 10D 從 -0.306% 推到 -0.142%、5D 從 -0.462% 推到 -0.362%，方向正確但沒過零。

**(b) 「不進場」閘門實質退化，不能當訊號用。**
定義「全池最高預測 q25 ≤ 0 → 不進場」在 dev 期旗標了 1D 97.7%~99.5%、5D 83.3%~91.1%、10D 74.3%~82.0% 的日子。扣成本後報酬分布的第 25 百分位幾乎永遠為負，所以這條規則幾乎每天都說「不進場」。後果：
- 「其他日」只剩 1D 約 4~17 天、5D 約 65~121 天，`diff_pp` 是和一個極小樣本比，數字大幅跳動（1D 從 +0.5927 跳到 -0.9617 只因 +C 讓非旗標日剩約 4 天），**沒有統計意義**。
- 1D baseline/+A/+B 的 diff 為正（旗標日反而比其他日好），方向與設計預期相反。
- 結論：閘門定義有誤，不是特徵不夠。此處不修，下一步見 §5。

**(c) C 族（大盤寬度）有害。** 設計預期「今天不進場主要靠這族」，但加入後 5D、10D Top-20 淨報酬顯著下降（-0.0847、-0.22pp，皆遠超 floor），5D/10D 校準誤差從 3.35/4.82 升到 5.64/6.97pp，超出 ±5pp。可能原因（未驗證，不作為救援理由）：大盤特徵在同一日對所有股票相同，對「同日排序」沒有資訊，只會讓樹把分裂花在時間 regime 上；dev 期只有三年、regime 樣本少，易過擬合年份。按規則 drop，不調參救。

**(d) 累積鏈的污染：DE 與 F 的 Δ 是在「含 C」的基礎上量的。** C 把 10D 拉掉 -0.22pp 後，DE（+0.0666）與 F（+0.054）的 10D 正增量有一部分可能只是在修補 C 造成的傷害，而非自身的邊際價值。因此 DE 的「insufficient evidence」與 F 的「keep」都是**有條件**的裁定：必須在去掉 C 的鏈（baseline+A+B → +DE → +F）上重量一次才算數。

**(e) 校準漂移。** 特徵越多，5D/10D 的 q25 被跌破率偏離 25% 越多（10D 3.35 → 6.97pp at +C，+F 仍 5.87pp）。q25 是排名分數本身，校準失準會直接讓「下緣」語意失真。

**(f) 副作用確認（未做）：** Top-20 內 `dist_limit_up` 分布是否明顯偏離全池（漲停股被看衰是否如設計預期）——用 JSON 無法直接看，列為下一步。

## 5. 下一步（優先序）

1. **重跑去 C 鏈**：baseline → +A → +B → +DE → +F（不含 C），同協定三種子。這是裁定 DE、F 的前提；不跑之前 DE 維持 insufficient evidence、F 的 keep 視為暫定。
2. **重新定義「不進場」閘門**（本輪不實作）：q25 ≤ 0 對扣成本分布近乎恆真，需換成非退化的條件，候選：(i) 全池最高預測中位數（q50）或 E[R_net] ≤ 0；(ii) Top-K 預測 q25 相對全池 q25 分布的位置（例如低於該日全池 q25 的某分位）；(iii) 以旗標率落在合理區間（例如 10%~40% 的日子）為設計約束反推門檻，只在 dev 定。
3. **5D/10D 為主戰場，1D 降級為診斷**：1D 在 0.585% 成本下 Top-20 中位數毛報酬為 0，屬機械性不可交易；後續驗收以 5D/10D Top-20 淨報酬為準。
4. 進 W2（ctx_matrix 池）機制過濾 ≤ 15 個 → 同協定加一步 "+W2"（接在第 1 點確定的鏈之後）。
5. 副作用檢查：Top-20 vs 全池的 `dist_limit_up` 分布、Top-20 的 vol20 分布（驗證 1D 選到低波動股的推論）。
6. 消息面資料層完成後 → "+W4" 獨立閘門（另一計畫）。
7. 通過族 → v3 凍結與產品化（另一計畫）；前提是至少一個 horizon 的 Top-20 dev 淨報酬能轉正或閘門修好後旗標日外的淨報酬為正，否則不進產品化。
8. 小清理：2026 年 `no_trade_pct` 0.51% 異常，查資料尾端 t+1 缺值是否被誤記為停牌。
