# Level 1 v3：隔日開盤進場目標 × 特徵重新研究 × 消息面資料層

日期：2026-09-28
狀態：設計定案（使用者核可），待實作
影響：FRS §5–7（Target）、§10（Feature）、§13/§16（驗收指標）、§14（Daily Pipeline）、§15（Ledger）、新增 §20（News Data Layer）
取代：v2 的「t 收盤 → t+N 收盤 橫斷面百分位」目標（`l1_lgbm_v2` 凍結並存，不下線）

## 0. 產品目標（使用者原話）

> 推薦下次開盤進場會賺錢的標的，上漲幅度、上漲機率越高名次越高。

翻成可計算的定義：

```
Entry  = O(i, t+1)                       隔日開盤價（模型 21:30 產出後最早可成交的價格）
Exit   = C(i, t+N)                       N ∈ {1, 5, 10} 並行
R_net  = C(i,t+N) / O(i,t+1) − 1 − c    c = 0.585%（一買一賣零售費率）
Score  = Q_0.25( R_net | X_t )           報酬分布下緣：「有 75% 機率至少賺多少」
Rank   = Score 降冪
```

同時輸出（不參與排名，只展示）：`E[R_net]`、`P(R_net > 0)`。

### 0.1 為什麼是下緣而不是期望值或機率

- 只看期望值 → 高波動彩券股霸榜（少數大漲拉高平均）。
- 只看機率 → 低波動、漲一點點的股票霸榜，扣成本後不賺。
- 下緣同時懲罰兩種：大漲但不穩的下緣低，穩但漲很少的下緣也低。

### 0.2 絕對報酬帶來的新能力：「今天不進場」

同日內，絕對報酬排序 ≡ 相對排序（大盤項對所有股票相同）。絕對報酬真正多出來的是**跨日資訊**：當全池第一名的 Score ≤ 0，展示層顯示「今天不建議進場」。這是 v2 做不到的。

### 0.3 與 v2 的關係

| | v2 | v3 |
|---|---|---|
| 進場價 | C(t)（買不到） | O(t+1) |
| 標籤 | 橫斷面百分位 | 絕對淨報酬 |
| 損失函數 | 回歸百分位 | quantile α=0.25 |
| 大盤資訊 | 只能靠交互項 | 直接進特徵 |
| 「不進場」 | 無 | 有 |

v2 已知 edge 主要在隔夜跳空與漲停鎖死（Level 2 三審定讞）。v3 預期 edge 會**縮水**，這是如實量測，不是退步。v2 ledger 與觀察紀律（5D ≥30 成熟日複評）**照舊不動**。

## 1. Target 規格（FRS §5–7 修訂）

### 1.1 成交可能性規則

| 情況 | 處理 |
|---|---|
| O(t+1) 為漲停價（依 tick 規則取整後等於 ⌊C(t)×1.10⌋_tick） | **未成交**：不進訓練標籤（NaN）；ledger 記 `fill_status='limit_up_unfilled'` |
| t+1 個股無成交（停牌） | 未成交，同上 `fill_status='no_trade'` |
| O(t+1) 為跌停價 | 視為成交（買得到，且這是模型該學會避開的） |
| C(t+N) 缺值（停牌／下市） | 標籤 NaN，不進分母 |

副作用要明講：「昨日鎖漲停、今日又跳空漲停」被排除，留下的是「昨日鎖漲停、今日開高沒鎖住」的失敗案例 → 模型會系統性看衰漲停股。**這是設計出來的可執行性偏誤，不是模型發現**。

### 1.2 成本

`c = 0.585%` 固定常數（Level 2 富果化成本模型已採納）。滑價不入標籤，由流動性特徵（Amihud）當代理讓模型自己學。

### 1.3 Universe 與評估母體

`U_t` 沿用 tradable universe（ADV20 ≥ 5,000 萬 ∧ 非處置），不變。
評估母體 `E_{t,N} = U_t ∩ 有效標籤`，其中有效標籤現在多一個「已成交」條件。

### 1.4 已知限制（延續）

close/open 未還原權息；除息日跳空會壓低當期 R_net。全市場股利資料不可得，維持文件化。
- 除息／除權日的漲跌停判定以未還原權息的 C(t) 計算：當日開盤若落在「真實」（還原權息後）
  跌停以下，仍可能被判為「成交」，因為比較基準本身已經被除息拉低。此為上一條限制的延伸，
  同樣因缺全市場股利資料而無法修正。
- `load_sector_map` 取的是目前的類股對照表，不是隨時間點的歷史對照（not point-in-time）；
  個股後來的類股重分類會回滲到 `sec_neutral_ret20` 這類特徵的歷史計算，等於用未來才知道
  的類股別去算過去的中性化報酬。

## 2. 特徵重新研究（FRS §10 重寫）

### 2.1 原則

1. **舊證據全部作廢**：v2 特徵的 IC 是在百分位目標上量的，對 R_net 的 q25 沒有推論力。每一族重新賺位置。
2. **先寫機制再進實驗**：每個候選要回答「為什麼會對『隔日開盤進場的淨報酬下緣』有用」。答不出來的不測。
3. **按角色分類，不按指標名**：direct signal / scale / context-gate / risk / execution。
4. **表示法由角色決定，不做雙表示**（使用者裁定）：
   - 方向訊號（動能、流動性比率、基本面）→ 每日橫斷面 rank，缺值補 0.5
   - 尺度／情境（波動、跳空、大盤、寬度）→ 原始值，缺值留 NaN 給 LightGBM 原生處理，**不補 0**
5. 移除 v2 的 4 個 `_bull` 交互項：那是給線性模型的補丁，GBM 有大盤原始特徵後自己會切。

### 2.2 候選水庫（不從 v2 出發）

| 水庫 | 內容 | 狀態 |
|---|---|---|
| W1 v2 特徵 | 11 價量 + 5 PIT 基本面 | 程式碼現成 |
| W2 ctx_matrix 特徵池 | ~98 個（含籌碼、注意力、`news_cnt5_pct`） | 程式碼現成，需接 Level1 資料流 |
| W3 新目標專屬 | 成交／隔夜、尺度、大盤寬度三族（§2.3） | 需新寫 |
| W4 消息面 | 新聞量／爆增、利空旗、題材旗、展望旗 | **需資料層先到位（§3）** |

刻意不重試：法人／融資（Gen1 否證 7/7）、董監持股（220 格 2 pass 結案）、ETF 成分事件（波動度代理）。若日後當 gate 再開題。

### 2.3 W3 新族規格

**A. 成交／隔夜（execution）**——新目標強制要有

| 名 | 公式 | 表示 | 機制 |
|---|---|---|---|
| `dist_limit_up` | C(t) / LimitUp(t) − 1，LimitUp 依 tick 取整 | 原始 | 越近越可能買不到或買在高點 |
| `lockup_days20` | 近 20 日 C = LimitUp 天數 | 原始 | 辨識 1D 幻影來源 |
| `gap_std20` | std(O(s)/C(s−1) − 1, 近 20 日) | 原始 | 個股隔夜風險尺度，直接壓下緣 |
| `overnight_minus_intraday20` | Σ(O/C₋₁−1) − Σ(C/O−1)，近 20 日 | 原始 | 動能住在隔夜的股票，開盤進場拿不到；用差值避免比例分母趨零 |

**B. 尺度（scale）**——給 q25 用，單看 IC 必弱，不因弱而丟

| 名 | 公式 | 表示 |
|---|---|---|
| `vol20` / `vol60` | 日報酬 std | 原始（v2 是 rank，**換**不是加） |
| `downside_vol20` | 只取負日報酬的 std | 原始 |
| `atr14_pct` | ATR14 / C | 原始 |

**C. 大盤／寬度（context-gate）**——「今天不進場」主要靠這族

| 名 | 公式 | 表示 |
|---|---|---|
| `mkt_ret5` / `mkt_ret20` / `mkt_vol20` | 加權指數 | 原始 |
| `breadth_ma20` | U_t 內 C > MA20 比例 | 原始 |
| `dispersion` | U_t 內當日報酬橫斷面 std | 原始 |

**只用 U_t 內股票算寬度與離散度**，不用全市場，否則與訓練母體不一致。

**D/E 補充**：`sec_neutral_ret20`（類股中性化強度，rank；`sec_ret20` 已知壞掉，先修）、`amihud20`（|r| / 成交金額 20 日均，rank；滑價代理）、`dollar_vol20` 改原始 log。

### 2.4 W4 消息面族規格（資料到位後）

所有消息面特徵 **lag 1 日**：新聞只有發布日期無時間，21:30 決策不能用當日 22:00 的新聞。這與 Gen1「法人／融資須 lag1」同一教訓。

| 名 | 公式 | 表示 | 機制 |
|---|---|---|---|
| `news_cnt5` / `news_burst` | 近 5 日則數；近 5 日 ÷ 近 60 日均 | rank | 注意力爆增 → 短期過度反應／延續 |
| `risk_flag3` | 近 3 日有 `is_risk` | 原始 0/1 | 利空後開盤跳空風險 |
| `theme_flag3` / `outlook_flag3` | 近 3 日有題材／展望分類 | 原始 0/1 | 催化劑 |
| `news_none60` | 60 日零新聞 | 原始 0/1 | 缺值 ≠ 零：無覆蓋 vs 真的沒新聞要分開 |

分類器沿用 `news_engine.classify`（關鍵字規則），不用 LLM 打歷史標籤（成本與可重現性）。情緒極性（正／負）**本輪不做**，先驗證「量」與「類別旗標」有沒有價值。

PTT：本輪不做。理由：個股層提及稀疏，屬大盤層散戶情緒，且要從零寫爬蟲。列為後續獨立題。

### 2.5 驗證協定

- **基準線**：5 特徵（`ret20`, `vol20`, `dollar_vol20`, `mkt_ret20`, `dist_limit_up`）+ q25 目標。所有比較對照這條。
- **一次加一族**：+A → +B → +C → +D/E → +W2 挑選 → +W4（獨立閘門，見下）。
- **三種子**（42/7/2024），dev = 2022-01~2024-12 walk-forward（126 日區塊、expanding、embargo=N），holdout 2025+ 只讀不調。
- **每步看四個數字**（dev）：
  1. Top-20 實際 `R_net` 均值與勝率
  2. q25 校準：預測下緣被跌破比例應 ≈ 25%（±5pp 內算校準）
  3. 「不進場」訊號：Score_max ≤ 0 的日子，U_t 等權 `R_net` 是否顯著低於其他日
  4. Rank IC（僅診斷，不當驗收）
- **增量門檻**：增量 < 三種子離散 → 噪音，不留。負結果照實記錄，不調參救。
- **消息面獨立閘門**：資料區間與價量不同，單獨一輪 ablation；先跑 `news_none60` 覆蓋率，覆蓋 < 60% 的年份不進 dev。
- **交互檢查**：A × N（1D 應最敏感）、C × 個股訊號（大盤好時動能是否更有效）——用 baseline / +A / +B / +A+B 四格比較，不做無界多項式。

## 3. 消息面資料層（新增 FRS §20）

### 3.1 現況（2026-09-28 量測）

`events` 表：1,277 筆、2026-07-27 起、132 檔（自選股）。訓練窗 2020–2024 **零覆蓋**。
FinMind `TaiwanStockNews` 免費層：一檔 × 一日一次呼叫 → 全池回補 ≈ 74 萬次 ≈ 50 天。

### 3.2 決策（使用者核可）

**FinMind 付費層**：整市場單日一次呼叫 → 2020-01 起回補 ≈ 1,250 次。

### 3.3 兩件資料工程（排最前，與價量研究並行）

1. **每日全池收錄**（從上線日起，不論回補進度）：排程新增 `NewsUniverseStep`，抓 U_t 全體（不只自選股），寫 `events`，append-only 去重不變。**必須記 `fetched_at`**（新欄位）——這是唯一能證明 PIT 的欄位，回補列的 `fetched_at` = 回補時間，與發布日分開，讓日後能區分「當時知道」與「事後補的」。
2. **歷史回補** `scripts/news_backfill.py`：2020-01-01 → 今，逐日整市場，節流依付費層限制，可中斷續跑（以日期為 checkpoint）。回補列 `source` 前綴標 `backfill:`。

### 3.4 回補資料的已知偏誤

- 事後存檔的新聞有生存偏誤（被刪／改標題的看不到）。
- 來源結構隨年份變（媒體增減）→ `news_cnt` 有時間趨勢，**用 rank 表示**可吸收一部分，仍需在 ablation 看逐年穩定性。
- 分類關鍵字是 2026 年寫的，套回 2020 有語彙漂移風險；旗標特徵逐年檢視。

## 4. 版本與 Ledger（FRS §14/§15）

- `MODEL_VERSION = l1_lgbm_v3`，三個 horizon 各一個 quantile 模型（α=0.25）+ 同特徵的 E[R] 回歸與 P(R>0) 分類，共 9 個模型／日（v2 三個模型 18 秒，容量無虞）。
- `level1_predictions` 新增欄：`score_q25`, `exp_ret`, `prob_up`, `fill_status`, `entry_open`, `actual_net_ret`。v2 列這些欄為 NULL。
- `--mature` 回填：用 O(t+1) 與 C(t+N) 算 `actual_net_ret`；漲停開盤寫 `fill_status`，`actual_net_ret` NULL。
- routes 以 `CURRENT_MODEL_VERSION` 過濾不變；board 新增三欄與「今日不建議進場」狀態；performance 的 Top-K 報酬改用 `actual_net_ret`，並另報「推薦但未成交」比例。
- **歷史回填 ledger 禁止**（v2 教訓不變）：訓練窗綁 pred_date 的修正已在 v2 落地，v3 沿用。
