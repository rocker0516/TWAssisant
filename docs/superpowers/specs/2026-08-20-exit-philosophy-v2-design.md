# 出場建議 v2 設計——雙軌雙哲學

日期：2026-08-20
狀態：已與使用者討論定案

## 背景與問題

現行出場引擎（`backend/app/engines/exit_engine.py` + `exit_signals.py`）是通用風控系統：
停損線、移動停利、技術轉弱、基本面轉弱、消息利空五類訊號，聚合成 🟢🟡🟠🔴 狀態燈。

核心矛盾：波段軌的進場端已定版目標函數「10 日內碰到 +10%，命中率為唯一 KPI」，
且經 backtest lab 驗證；出場端卻是另一套未驗證的手設參數（-8%、10%/10%），
且**沒有時間維度**——第 10 天未達標的持股依目標函數已是未命中，出場引擎卻可能一直 🟢。

## 決策紀錄（討論定案）

| 問題 | 選項 | 定案 |
|---|---|---|
| 出場哲學 | 論點失效 / 風控 / 重新選擇 / 混合 | **混合分層**：波段=論點失效說、長線=風控+基本面 |
| 波段到期未達標 | 硬出場 / 到期重審 / 漸進衰減 | **到期重審**（重跑進場條件，通過則時鐘歸零，上限 2 次） |
| 波段碰到 +10% | 即出場 / 轉移動停利 / 轉停利+保底 | **兌現即出場**（統計口徑一致，續漲屬未驗證盲區） |
| 波段中途反證 | 只停損線 / +條件失效 / +結構反證 | **只停損線**（繼承回測口徑，零新增自由參數） |
| 長線軌 | 照留 / 小修 / 改重新選擇說 | **小修**（長線分數當基本面主訊號，風控線照舊） |

## 1. 哲學

- **波段軌＝論點失效說**：出場規則完全由進場論點推導，只有三個出口
  （兌現／過期／反證），不存在獨立的技術面出場訊號。
- **長線軌＝風控＋基本面**：維持現行聚合架構，訊號小修。
- 狀態燈聚合骨架（🟢🟡🟠🔴、Sev 分級、`_aggregate`）兩軌共用，不動。

## 2. 波段軌：論點狀態機

### 論點快照

回測的停損/目標/天期**不是全域常數，是每個策略的參數**
（`strategy_engine.run_backtest` 的 `target_pct` / `horizon_days` / `stop_pct`，
進場錨＝訊號隔日 high）。因此每筆波段持股**開倉時快照**：

- `target_pct`、`horizon_days`、`stop_pct`
- 進場條件來源（lab 策略的條件 JSON，或推薦引擎來源標記）
- 時鐘起算日

手動建倉、無策略來源者：套全域預設（10 日 / +10% / 預設停損），UI 標示「非策略持股」。

### 三個出口（優先序同回測：同日先判停損）

1. **反證**：最低價碰到 `avg_cost × (1 − stop_pct)` → 🔴「論點反證，停損出場」。
   快照無 stop_pct 者退回全域預設。
2. **兌現**：持有期間 high 碰到 `avg_cost × (1 + target_pct)` → 🔴「論點兌現，獲利了結」，
   同時記一筆命中（供命中率統計；之後續抱盈虧不污染波段 KPI）。
3. **過期**：時鐘走到 `horizon_days` 未兌現 → 當日重跑進場條件：
   - 通過 → 時鐘歸零、`reaudit_count` +1（**上限 2 次**，超過直接 🔴）、
     燈維持 🟢，UI 顯示「已重審 n/2」。
   - 不通過 → 🔴「論點過期」。

### 中間狀態燈

- 正常持有 🟢。
- 倒數 2 個交易日內未兌現 → 🟡（到期預告，非賣出訊號）。
- 到期日當天等待重審結果 → 🟠。
- **例外反證**：處置警示（交易機制被改變，論點前提不成立）→ 🟠。
- 其餘現有訊號對波段軌**全部停用**：TrailingStop、TechWeak（均線空頭/KD 死叉/爆量長黑）、
  一般利空消息。

### 口徑

- **天數**：與回測一致——訊號隔日為第 1 天，交易日計。
- **價格錨**：用使用者實際 `avg_cost`。回測錨（隔日 high）較保守，實際成本通常更低，
  實盤命中率 ≥ 回測值，方向安全。

## 3. 長線軌：小修

- **主訊號改為長線分數滑落**：開倉時記錄長線分數基準；
  現分數（取近 5 日均值，防月營收/季報發布造成的階梯跳動）較基準滑落超過門檻 → WARN；
  滑落且跌破持有門檻 → CRITICAL。
- 原「月營收年增轉負」降級：yoy < 0 維持 EARLY；yoy < −10 由 CRITICAL 降為 **WARN**
  （讓分數當主判官）。
- **法人連賣**：觀察窗由 10 日拉長至 **20 日**，門檻比例不變（降噪）。
- 風控線照舊：−15% 硬停損、破季線、移動停利 20%/20%、消息利空。

## 4. 聚合與 UI

- `_aggregate` 不動。`ExitStatus` 增加波段欄位：
  `thesis_state`（active/expiring/fulfilled/expired/refuted）、`days_left`、
  `reaudit_count`、`target_price`、`stop_price`。
- 持股卡（波段）：訊號列表改為**論點進度條**——第 n/N 天、距目標 %、距停損 %；
  兌現後顯示「已命中」徽章。
- Discord：沿用 🔴🟠 推播；新增到期日前一日預告訊息。

## 5. 設定頁與遷移

- 移除波段軌 stop_cap / trail_trigger / trail_pullback 設定項。
- 新增：「非策略持股預設」（stop / target / horizon 三項）、重審上限次數、
  長線「分數滑落門檻」。
- 長線軌現有設定不變。
- 一次性遷移：既有開倉中的波段持股，無快照者套全域預設，時鐘自遷移日起算。

## 6. 驗證

- 單元測試：三出口優先序（同日碰停損與目標 → 判停損）、重審保險絲上限、
  天數口徑（隔日起算）、非策略持股預設 fallback。
- 消融實驗（後續，不擋上線）：backtest lab 增「出場規則消融」——
  同批進場樣本比較「純三出口」vs「＋破月線反證」的實拿報酬分佈，
  用數據決定月線反證是否加回。
- 長線分數滑落門檻：先上保守值（如滑落 15 分 WARN），
  以 backfill_scores 歷史分數分佈校準後再調。

## 非目標

- 不改進場端任何邏輯與 KPI 定義。
- 不在本次加入類股走弱、大盤狀態等新出場訊號。
- 不做部分出場（分批賣）建議。
